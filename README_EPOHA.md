# ЭПОХА — КОМПЬЮТЕРНЫЙ КЛУБ 2000—2015

Epoha Shell 0.1.1 — тестовая Win7-safe сборка.

- Windows 7 SP1 x86/x64;
- .NET Framework 3.5 / CLR 2.0;
- EXE собран как x86 для максимальной совместимости;
- конфигурация: `%LOCALAPPDATA%\Epoha\config.xml`;
- аварийный лог: `%LOCALAPPDATA%\Epoha\crash.log`;
- клубные ограничения по умолчанию выключены;
- пароль администратора первого запуска: `2000`;
- аварийный вход: `Ctrl+Alt+E`.

В версии 0.1.1 клавиатурный hook не создаётся при обычном запуске — только после явного включения клубных ограничений. При необработанной ошибке оболочка должна показать окно с текстом ошибки и записать crash.log.

До завершения тестов не назначайте ЭПОХУ системным shell и не включайте клубные ограничения.
