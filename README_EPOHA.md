# ЭПОХА — КОМПЬЮТЕРНЫЙ КЛУБ 2000—2015

Epoha Shell 0.3.0 — Windows 7 compatible test build.

Текущий этап:
- единая двухколоночная компоновка без наложений;
- выравнивание логотипа по высоте шапки;
- визуальные кнопки администратора, перезагрузки и выключения;
- устранение мерцания за счёт двойной буферизации и отказа от полной перелайаутки на каждом тике часов;
- пользовательские обои;
- космический фон;
- улучшенные карточки игр;
- рабочие настройки администратора: общие, внешний вид, вкладки, игры и ярлыки, система;
- конфигурация хранится в `%LOCALAPPDATA%\Epoha\config.xml`.

Пароль первого запуска: `2000`.

Клубные блокировки Windows будут подключаться после стабилизации интерфейса и админки.
