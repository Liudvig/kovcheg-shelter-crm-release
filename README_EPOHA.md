# ЭПОХА SHELL

Тестовая ветка оболочки компьютерного клуба «ЭПОХА» (2000—2015).

Текущая тестовая линия: **0.6.0**.

Основные направления 0.6.0:
- переработанный интерфейс в духе компьютерных клубов 2009—2012;
- единые обои на весь экран;
- стеклянные панели и адаптивная прозрачность;
- улучшенные карточки игр и автоматическое использование иконки EXE при отсутствии обложки;
- часы и дата без отдельной прямоугольной подложки;
- расширенная админка и настройки внешнего вида;
- режим обслуживания, Explorer и выключение Shell;
- экспериментальный клубный режим с пользовательскими ограничениями Windows;
- экспорт/импорт конфигурации для переноса на другие ПК.

Сборка предназначена для тестирования на Windows 7 x86/x64. Клубные ограничения по умолчанию не должны включаться автоматически на новом конфиге.
