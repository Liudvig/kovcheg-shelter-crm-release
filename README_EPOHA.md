# ЭПОХА Shell 0.1

Тестовый полноэкранный shell для Windows 7.

Возможности:
- адаптивная сетка под 5:4, 16:10, 16:9;
- вкладки слева;
- администраторское меню;
- добавление/редактирование ярлыков игр;
- часы, подпись ПК, выключение и перезагрузка;
- клубные ограничения: Win, Alt+Tab, Alt+F4, Ctrl+Esc + DisableTaskMgr;
- переключение shell текущего пользователя между EpohaShell.exe и explorer.exe;
- аварийный вход администратора: Ctrl+Alt+E;
- настройки: %ProgramData%\Epoha\config.xml.

Пароль администратора при первом запуске: 2000.

Важно: Ctrl+Alt+Del (Secure Attention Sequence) приложение не блокирует. Это системно защищённая комбинация Windows.
